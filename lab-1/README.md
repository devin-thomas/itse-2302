# Lab 1 - XAMPP

This lab sets up a local Apache, MariaDB/MySQL, and PHP development environment
with XAMPP. The project page confirms that PHP files are being served from the
local XAMPP document root.

## Files

- `index.php` - required project page displaying Devin Thomas
- `status.php` - optional local status page for Apache and MySQL
- `xampp-status.command` - macOS command-line status check
- `MACOS-WALKTHROUGH.md` - notes from the initial macOS installation

## Continue on Windows

1. Install XAMPP in `C:\xampp`.
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Create `C:\xampp\htdocs\project`.
4. Copy `index.php` and, optionally, `status.php` into that folder.
5. Visit `http://localhost/project/index.php`.
6. Capture the XAMPP Control Panel, welcome page, and project page with the
   browser address bar visible.

The local server is intended for coursework and development, not public
hosting.
